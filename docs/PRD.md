## 1. 产品背景与目标

用户需要将图片转换为适合网页、应用或日常分享的格式，并在画质、像素尺寸和文件体积之间找到合适的平衡。

IMGX 参考 Squoosh 的压缩前后对比思路，结合 Mac 的本地文件操作习惯，提供“导入—设置—对比—批量导出”的工作流程。

### 产品目标

1. 支持批量转换，减少重复操作。
2. 在导出前看到真实编码后的画质与文件体积。
3. 所有图片在本机处理，保留原文件。
4. 以图片预览为视觉中心，常用设置直接操作，高级设置按需展开。
5. 使用黑白灰为主的原生 Mac 界面，减少装饰与无效留白。

### 目标用户与场景

以下用户定位根据已确认需求归纳，尚未经过独立用户调研。

| 用户类型 | 核心场景 |
|---|---|
| 设计师、内容创作者 | 压缩图片素材，检查透明边缘和画质细节 |
| 前端及应用开发者 | 将素材批量转换为 WebP，降低资源体积 |
| 日常 Mac 用户 | 批量调整图片尺寸，转换常用格式用于分享或上传 |

## 2. 版本范围

### 本版包含

- JPG、JPEG、PNG、WebP、HEIC 静态图片导入。
- WebP、JPEG、PNG 输出。
- 多图片列表及统一参数批量转换。
- 实际编码结果预览与体积比较。
- 滑杆、左右分屏两种对比方式。
- 滚轮及捏合缩放、拖动平移、适应窗口。
- 质量设置、WebP 无损模式。
- 原尺寸、50%、25%、自定义尺寸。
- 文件夹导出、同名自动编号、单张失败继续处理。
- 拖入蒙层、浮动提示、常用快捷键。

### 本版不包含

- 动图转换或动画保留。
- HEIC 输出及其他未列出的输出格式。
- 裁剪、旋转编辑、滤镜、水印。
- 为每张图片单独保存不同参数。
- 文件夹递归导入。
- 导出任务暂停、取消、断点续传。
- 历史任务、设置持久化、云同步。
- 原图元数据的完整保留承诺。

## 3. 核心用户流程

1. 启动应用，进入居中的空状态。
2. 拖入图片，或点击“选择图片”。
3. 应用展示文件侧栏，默认选中第一张图片并生成预览。
4. 用户调整格式、质量或尺寸。
5. 当前选中图片重新编码，更新画质预览和体积数据。
6. 用户通过滑杆、分屏、缩放和平移检查差异。
7. 点击“导出 N 张图片”，选择保存文件夹。
8. 应用按统一参数逐张处理，更新列表状态和完成数量。
9. 导出结束后，以浮动提示展示成功数量与保存位置。

## 4. 页面结构与状态

### 4.1 空状态

无图片时：

- 隐藏文件侧栏。
- 隐藏“预览”、体积信息、对比切换和“适应窗口”。
- 隐藏底部工具栏。
- 背景铺满窗口，不出现外围白边或独立卡片边界。
- 中央依次展示：
  1. APP 图标；
  2. “图片压缩与转换”；
  3. “本地处理 · 多格式输出 · 保留原文件”；
  4. “选择图片…”按钮；
  5. “或将图片拖到窗口中”；
  6. 支持的输入格式。

启动时不自动聚焦尺寸输入框。

### 4.2 有图片状态

界面分为四部分：

| 区域 | 内容 |
|---|---|
| 左侧栏 | 品牌、添加图片、文件卡片、图片数量、移除和清空操作 |
| 顶部结果栏 | 预览标题、转换前后体积、变化比例、对比模式、适应窗口 |
| 主画布 | 原图与转换后图片、棋盘格背景、滑杆及操作提示 |
| 底部单行工具栏 | 格式、质量、尺寸预设、更多设置、导出按钮 |

移除最后一张图片或清空列表后，恢复空状态。

### 4.3 拖入状态

文件进入窗口、鼠标尚未松开时：

- 显示覆盖内容区域的圆角磨砂蒙层。
- 下方界面使用轻微模糊与透明度变化，中央提示保持清晰。
- 显示“松开以添加图片”、支持格式及保留原文件说明。
- 拖离或完成投放后，蒙层消失。
- 转换期间不显示可继续添加的提示。
- 尊重系统“降低透明度”设置。

## 5. 功能需求

### 5.1 图片导入与文件管理

**导入规则**

- 支持一次选择或拖入多个文件。
- 接受 `.jpg`、`.jpeg`、`.png`、`.webp`、`.heic`。
- 同一文件 URL 重复导入时不重复添加。
- 追加导入保留已有列表。
- 无选中项时，默认选中列表第一项。
- 扩展名不受支持的文件跳过，并提示数量。
- 扩展名受支持但实际无法解码的文件，在预览或转换阶段报错。

**文件卡片**

展示缩略图、文件名、原始体积和处理状态。长文件名中间截断，悬停可查看完整文件名。

卡片可见背景与“添加图片”按钮左右对齐，内容保留适量内边距；选中背景使用灰色，滚动条隐藏。

**移除规则**

- “移除选中”：仅从列表移除当前图片。
- Backspace/Delete：非文字编辑状态下移除当前选中图片。
- 删除后优先选择原位置的下一项；没有下一项时选择上一项。
- “清空列表”：移除全部列表项。
- 所有移除操作均不删除原文件。
- 转换期间禁用添加、移除和清空。

### 5.2 输出格式与压缩

| 输出格式 | 默认扩展名 | 质量控制 | 透明通道 |
|---|---|---|---|
| WebP | `.webp` | 1～100；支持无损模式 | 保留 |
| JPEG | `.jpg` | 1～100 | 不支持，透明区域铺白 |
| PNG | `.png` | 无损编码，质量滑块禁用 | 保留 |

默认设置：

- 格式：WebP。
- 质量：80。
- WebP 无损模式：关闭。
- 尺寸：原尺寸。

JPG 与 JPEG 合并为一个“JPEG”输出选项，输入仍接受两种扩展名。

启用 WebP 无损模式后，质量滑块禁用，显示“无损”。切换至 PNG 时同样显示“无损”。

### 5.3 尺寸设置

常用尺寸通过底部下拉框选择：

| 选项 | 规则 |
|---|---|
| 原尺寸 | 不主动缩放 |
| 50% | 每张图片宽高分别缩放至原来的 50% |
| 25% | 每张图片宽高分别缩放至原来的 25% |
| 自定义 | 打开高级设置，填写宽高 |

自定义尺寸规则：

- 单位为像素。
- 输入宽度，按当前选中图片的比例计算高度。
- 修改高度，按相同比例计算宽度。
- 清空主动编辑的一项时，另一项同时清空。
- 宽高均为空时使用原尺寸。
- 批量转换时，各图片保持自身比例，放入所设置的宽高范围内，不强制拉伸。
- 切换选中图片时，自定义参数按最近编辑方向重新联动。
- 正整数范围为 1～16383；无效值提示错误。
- 当前实现允许放大图片。

当前编码限制：输出任一边不超过 16383px，输出总像素不超过 1 亿。

### 5.4 实际编码预览

- 预览通过实际编码生成，不使用估算体积。
- 预览图来自编码后文件的解码结果。
- 质量、格式或尺寸变化后自动刷新。
- 连续修改参数时采用约 300ms 延迟，减少重复刷新。
- 只预览当前选中图片，不提前转换整个列表。
- 过期预览结果不得覆盖最新参数对应的结果。
- 生成过程中显示加载状态。

顶部结果展示：

- 原始文件体积；
- 输出文件体积；
- 体积减少或增加比例。

计算方式：

`体积减少比例 =（1－输出体积 ÷ 原始体积）× 100%`

减少使用浅绿色背景，增加使用浅橘色背景，并同时提供文字说明。原始与输出像素尺寸可通过结果区域的悬停说明查看。

### 5.5 对比画布

默认使用滑杆模式：

- 左侧为原图，右侧为转换结果。
- 拖动分界线改变两侧可见范围。
- 拖动图片区域进行平移。

分屏模式：

- 左侧完整显示原图，右侧完整显示转换结果。
- 两侧共享缩放和平移参数，便于比较同一位置。

通用交互：

- 滚轮与触控板捏合均支持缩放。
- 缩放围绕指针位置进行。
- 按住拖动图片平移。
- 双击、点击“适应窗口”或使用复位快捷键恢复适应窗口。
- 切换图片重置缩放和平移。
- 两种模式均使用铺满画布的灰色棋盘格。
- 棋盘格不随图片缩放和平移。
- 文字标签采用圆角半透明底板，适配深浅色模式。
- 图片区域悬停显示张手，拖动显示握手，分界线区域显示左右调整指针。

**缩放口径：**当前显示的 100% 表示“适应窗口”的基准比例，不是图片像素与屏幕像素一一对应。

### 5.6 高级设置

点击底部“更多设置”图标展开弹层，包含：

- WebP 无损压缩开关；
- 当前格式的透明通道处理说明；
- 自定义宽高及像素单位；
- 等比联动说明；
- “完成”关闭按钮。

点击尺寸下拉框中的“自定义…”也会展开弹层。

点击输入框外结束编辑，保留正常的文字删除和 Tab 键导航。

### 5.7 批量导出

- 按钮明确显示“导出 N 张图片”。
- 导出范围为列表全部图片，选中项仅决定预览对象。
- 点击后选择保存文件夹。
- 按点击导出时的参数快照处理全部图片。
- 按顺序逐张转换并写入文件。
- 导出期间显示已处理数量。
- 单张失败记录错误，继续处理后续图片。
- 导出结束提示成功数量、总数量和保存位置。

**命名与文件保护**

- 默认保留原文件主体名称，更换扩展名。
- 同名文件存在时自动追加 `-1`、`-2` 等编号。
- 不覆盖原图或已有输出文件。
- 原文件所在目录也可作为输出目录，仍执行防覆盖规则。

列表状态包括：待转换、转换中、完成及输出体积、失败及原因。

### 5.8 通知与错误反馈

使用浮动 toast，叠加在页面上，不改变布局，不产生底部白色区域。

| 情况 | 展示规则 |
|---|---|
| 跳过不支持文件 | 提示数量与支持格式，5 秒后消失 |
| 转换完成 | 提示成功数、总数与保存位置，5 秒后消失 |
| 预览失败或参数错误 | 持续显示，直到关闭、被新通知替换或问题修正 |

所有提示均可手动关闭。重复触发普通提示时重新计时。混合导入有效和无效文件时，跳过提示不应被预览成功事件提前清除。

## 6. 视觉与交互规范

- 主色调为黑白灰，状态反馈按含义使用绿色与橘色。
- 对比切换使用原生 Segmented 控件，选中底色为深灰。
- 图片预览占主要空间，不恢复独立结果行或大面积设置卡片。
- 顶部多余标题栏留白移除，同时避让窗口控制按钮。
- 文件卡片、预览标签、浮层采用协调的圆角与留白。
- 应用图标使用 `inset.left.half.square.dashed.micro`，明亮近白底板、深色符号和轻微阴影。
- 图标主体尺寸参照本机 Finder 校准。
- 适配系统深浅色、“降低透明度”和“增强对比度”相关设置。
- 当前已补充部分无障碍标签与键盘操作，不宣称已完成全面无障碍验收。

### 常用键盘操作

| 操作 | 快捷键或按键 |
|---|---|
| 添加图片 | ⌘O |
| 导出全部图片 | ⌘Return |
| 适应窗口 | ⌘0 |

| 预览缩放 | `+` / `-` |

| 调整滑杆分界线 | `[` / `]` |

## 7. 运行与数据边界

- 原生界面使用 SwiftUI 与 AppKit。
- 图片在本地读取、编码和保存，无需上传。
- 当前构建面向 Apple Silicon，最低系统版本为 macOS 26。
- 最小窗口尺寸为 1000×700pt。
- WebP 编码库静态链接，生成应用运行时无需 Homebrew。
- 当前为本地开发分发包，使用临时签名，尚未进行正式开发者签名、公证或 App Store 发布。
- 输入列表和设置不跨启动保存。
- 不保证原图 EXIF、ICC 等元数据完整保留，也未定义专业色彩管理验收标准。
- 压缩结果可能比原文件更大，必须如实展示，不承诺固定压缩率。

以下为当前代码边界或后续验收事项，不属于本版已完成承诺：

## 10. 产品成功标准

本版以可验证的工作流完成度作为验收依据：

- 用户无需离开应用即可完成导入、对比、设置和批量导出。
- 预览体积与相同参数、相同源文件的实际导出体积一致。
- 文件保护规则可靠，不因转换或列表移除破坏原文件。
- 常用操作直接可见，高级选项不持续占用预览空间。
- 空状态、处理状态、成功与失败状态具有清晰反馈。

当前未接入产品埋点，不将未经采集的使用率、速度或满意度数据写成既有成果。
